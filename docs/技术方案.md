## 0. 设计约束（承自需求文档）

| 约束 | 内容 |
|---|---|
| local-first | 本地为真源；离线全功能可用（AI 可走本地 LLM）；跨设备同步为可选开关 |
| AI 全流程介入 | 读前/读中/读后/复习四阶段，AI 以 Skill 形式介入 |
| YAGNI（v1） | v1 = #1 RIA + #6 SuperMemo 最小闭环 + 支撑功能（书库/AI对话/TTS/Skills） |
| 引擎解耦 | foliate-js（vendor+patch）与 AI/数据层解耦，可替换 |
| 语言/栈 | TypeScript（全栈）+ React + Tauri(桌面)；SQLite；v1 仅 EPUB |
| 隐私 | 所有数据默认本地存储；云端（TTS 云 / 外部 AI API）仅用户显式开启，且只传必要字段（承需求 NF5） |

## 1. 整体架构（分层）

```

├─────────────────────────────────────────────────────────────────────┤
│  数据层   (packages/core/db)                                          │
│   SQLite 双库: main.db(可同步) + local.db(向量, 不同步)               │

│                   reading_sessions/method_artifact/review_items       │
├─────────────────────────────────────────────────────────────────────┤
│  引擎层   (packages/engine, foliate-js vendored + patch)             │
```

**数据流（读中 RIA 为例）**：
用户在引擎层选中一段 → UI 触发 `ria_note` Skill（技能层）→ Skill Runtime 调 Capability Catalog 工具（`reader.getSelection` 取原文+CFI+前后文；`retrieval.search` Hybrid 检索全书上下文）→ AI 层 Provider 生成 I/A → 数据层写 `method_artifact(method='ria_note')`（含 context）→ UI 渲染三栏便签。

## 3. 接口设计（关键签名；TypeScript）

### 3.1 引擎层 `Engine`
```ts
interface Engine {
  loadBook(src: EpubSource): Promise<BookHandle>;      // src = 本地文件 / ArrayBuffer
  render(handle: BookHandle, opts?: RenderOpts): Promise<RenderedPage>;
  currentCfi(handle: BookHandle): string | null;        // CFI 稳定寻址
  goToCfi(handle: BookHandle, cfi: string): Promise<void>;
  nextPage/prevPage(handle: BookHandle): Promise<RenderedPage | null>;
  // AI 注入钩子（借 foliate-js transformTarget）：
  transform(handle: BookHandle, target: Selector, tf: TransformFn): Promise<TransformResult>;
  // 全文遍历（skipHiddenText 选项）：
  textWalker(handle: BookHandle, opts?: { skipHiddenText?: boolean }): TextIterator;
}
type TransformFn = (node: Element) => Node | true | false | null; // 替换/保留/删除
```

### 3.2 AI 层 `AIProvider` + `Retriever`
```ts
interface AIProvider {
  chat(messages: ChatMessage[], tools?: ToolSpec[], opts?: ChatOpts): Promise<AIChatResult>;
  summarize(text: string, instruction?: string): Promise<string>;
  embed(texts: string[]): Promise<number[][]>;          // 向量（本地模型）
}
interface Retriever {
  // Hybrid：FTS5(关键词) + 向量(语义)，RRF 融合
  search(query: string, ctx: { bookId: string; topK?: number }): Promise<RetrievalHit[]>;
}
interface RetrievalHit { cfi: string; text: string; source: 'fts'|'vector'; score: number }
```

### 3.3 技能系统 `SkillManifest` / `CapabilityCatalog` / `SkillRuntime`
```ts
type SkillKind = 'prompt' | 'agent' | 'script';
type AccessLevel = 'none' | 'read' | 'write' | 'full';
interface SkillManifest {
  schemaVersion: number; id: string; kind: SkillKind;
  source: 'builtin'|'user'; name: string; description: string;
  access: AccessLevel; tools: string[];                 // Capability Catalog 白名单
  prompt?: { inline?: string; path?: string };
  script?: { enabled: boolean; runtime: 'node'|'quickjs'; entry?: string };
}
interface CapabilityTool { name: string; description: string; access: AccessLevel; inputSchema: unknown }
interface SkillRuntime {
  invoke(manifest: SkillManifest, ctx: SkillRunContext): Promise<SkillResult>;
}
interface SkillRunContext { skillId: string; bookId?: string; selectedText?: string; cfi?: string; args?: Record<string,unknown> }
```

### 3.4 TTS 层 `TTSEngine`（可插拔）
```ts
interface TTSEngine {
  id: string; label: string; voices(): Promise<Voice[]>;
  synthesize(text: string, voice?: string): AsyncIterable<AudioChunk>;   // 流式
}
```

### 3.5 公共类型（shape sketch；实施期精化）

> 以下为 §3.1–§3.4 接口签名引用的共享类型的**形状速写**（key fields）；精确定义在实施期按各层细化。列出以消除接口签名中的悬空引用（承 writing-plans「no placeholders」纪律）。

- `EpubSource`：EPUB 载入源 = `{ filePath?: string; arrayBuffer?: ArrayBuffer }`（本地文件 或 内存缓冲）。
- `BookHandle`：载入后的书句柄 = `{ bookId: string; coverUrl?: string }`（引擎内部，不直接暴露给 UI）。
- `RenderOpts`：渲染选项 = `{ width?: number; height?: number; theme?: 'light'|'dark'; fontScale?: number }`。
- `RenderedPage`：渲染结果 = `{ cfi: string; html: string; index: number; total: number }`。
- `Selector`：transformTarget 目标选择器 = CSS selector string（如 `'body p'`）。
- `TextItem` / `TextIterator`：全文遍历项 = `{ cfi: string; text: string; hidden?: boolean }`；迭代器 = `Iterable<TextItem>`。
- `ChatMessage`：AI 对话消息 = `{ role: 'user'|'assistant'|'system'; content: string; citations?: RetrievalHit[] }`。
- `ToolSpec`：AI 可调工具描述 = `{ name: string; description: string; inputSchema: unknown }`（对齐 CapabilityTool）。
- `ChatOpts`：chat 选项 = `{ temperature?: number; maxTokens?: number }`。
- `AIChatResult`：chat 结果 = `{ content: string; toolCalls?: { name: string; args: unknown }[]; usage?: { promptTokens: number; completionTokens: number } }`。
- `SkillResult`：skill 运行结果 = `{ ok: boolean; data?: unknown; error?: string }`。
- `Voice`：TTS 音色 = `{ id: string; label: string; lang?: string }`。
- `AudioChunk`：TTS 流式音频块 = `{ data: ArrayBuffer; format: 'mp3'|'wav'|'ogg' }`。

## 4. 数据模型（v1 schema DDL；SQLite）

> 双库：`main.db`（可同步，用户数据）+ `local.db`(向量 chunks，不同步)。外键 ON；WAL。
> 以下为 **v1 需建的 9 张表**（concrete DDL；字段承自 `持久数据模型对比.md`）。

```sql
-- ============ main.db（可同步）============
CREATE TABLE books(
  id TEXT PRIMARY KEY, file_path TEXT NOT NULL, format TEXT NOT NULL DEFAULT 'epub',
  title TEXT NOT NULL, author TEXT, publisher TEXT, language TEXT, isbn TEXT,
  description TEXT, cover_url TEXT, publish_date TEXT, rating REAL,
  tags TEXT NOT NULL DEFAULT '[]',          -- JSON（v1 反范式；v2+ 可拆 junction）
  progress REAL DEFAULT 0, current_cfi TEXT, added_at INTEGER NOT NULL, last_opened_at INTEGER,
  updated_at INTEGER NOT NULL               -- 同步用（v2+ 加 sync_version/last_modified_by/deleted_at）
);
CREATE TABLE annotations(                   -- 划线/批注，含上下文（一等需求）
  id TEXT PRIMARY KEY, book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  cfi TEXT NOT NULL, text TEXT NOT NULL,
  context_before TEXT, context_after TEXT,    -- ★ 离线 AI 依据
  color TEXT DEFAULT 'yellow', style TEXT DEFAULT 'highlight', type TEXT DEFAULT 'annotation',
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE TABLE notes(                          -- 自由笔记（可挂 highlight）
  id TEXT PRIMARY KEY, book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  highlight_id TEXT REFERENCES annotations(id) ON DELETE SET NULL,
  cfi TEXT, title TEXT NOT NULL, content TEXT NOT NULL,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE TABLE threads(                        -- AI 对话（规范化，非 JSON-blob）
  id TEXT PRIMARY KEY, book_id TEXT REFERENCES books(id) ON DELETE SET NULL,
  title TEXT, memory_summary TEXT,            -- 滚动记忆（控 token）
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE TABLE messages(                       -- 规范化消息表
  id TEXT PRIMARY KEY, thread_id TEXT NOT NULL REFERENCES threads(id) ON DELETE CASCADE,
  role TEXT NOT NULL, content TEXT NOT NULL,
  citations TEXT DEFAULT '[]', tool_calls TEXT DEFAULT '[]', reasoning TEXT, parts_order INTEGER,
  created_at INTEGER NOT NULL
);
CREATE TABLE skills(                         -- 预置 + 自定义 Skill（承 ReadAny manifest 兼容层）
  id TEXT PRIMARY KEY, name TEXT NOT NULL UNIQUE, description TEXT, icon TEXT,
  kind TEXT NOT NULL DEFAULT 'prompt',        -- prompt/agent/script（= SkillManifest.kind）
  source TEXT NOT NULL DEFAULT 'user',         -- builtin/user/imported（= SkillManifest.source）
  access TEXT NOT NULL DEFAULT 'none',         -- none/read/write/full（= SkillManifest.access）
  tools TEXT NOT NULL DEFAULT '[]',            -- Capability Catalog 白名单 (JSON) = SkillManifest.tools
  enabled INTEGER DEFAULT 1,                    -- 启用开关（= SkillManifest.enabled）
  manifest_json TEXT NOT NULL DEFAULT '{}',    -- 完整 SkillManifest（schemaVersion / prompt{inline,path} / script{...}）
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE TABLE reading_sessions(               -- 阅读会话时间序列（复习/习惯分析基础）
  id TEXT PRIMARY KEY, book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  started_at INTEGER NOT NULL, ended_at INTEGER, total_active_time INTEGER DEFAULT 0,
  pages_read INTEGER DEFAULT 0, state TEXT DEFAULT 'active', updated_at INTEGER NOT NULL
);
CREATE TABLE method_artifact(               -- ★ 多态单表：8法 AI 产物（v1 仅 ria_note）
  id TEXT PRIMARY KEY, book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  method TEXT NOT NULL,                     -- ria_note|four_level|three_pass|tower|mckinsey|celebrity|munger|resonance
  content TEXT NOT NULL,                    -- JSON（方法特定结构）
  idempotency_key TEXT,                     -- 生成幂等键
  helpful INTEGER DEFAULT 0, dismissed INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE TABLE review_items(                  -- ★ SuperMemo 间隔重复（独立表）
  id TEXT PRIMARY KEY, book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  source_artifact_id TEXT REFERENCES method_artifact(id) ON DELETE SET NULL,
  question TEXT NOT NULL, answer TEXT NOT NULL, context TEXT,
  due_date INTEGER NOT NULL, interval_days REAL DEFAULT 1, ease_factor REAL DEFAULT 2.5,
  lapses INTEGER DEFAULT 0, retrieval_count INTEGER DEFAULT 0, last_reviewed_at INTEGER,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);

-- ============ local.db（本地专用，不同步）============
CREATE TABLE chunks(                         -- 向量嵌入（Hybrid 检索用）
  id TEXT PRIMARY KEY, book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  chapter_index INTEGER, chapter_title TEXT, content TEXT NOT NULL, token_count INTEGER,
  start_cfi TEXT, end_cfi TEXT, segment_cfis TEXT DEFAULT '[]',
  embedding BLOB,                            -- float32 向量
  updated_at INTEGER NOT NULL
);
CREATE TABLE vector_index_provenance(        -- ★ 嵌入出处（换模型即作废）
  book_id TEXT PRIMARY KEY, model_kind TEXT, model_id TEXT, endpoint TEXT, dimensions INTEGER, created_at INTEGER NOT NULL
);
```

**v2+ 增表**（实施期建）：`concept_tags` / `concept_edges`（知识图谱）、`margin_notes`（跨书边注）；`method_artifact.method` 新增 7 个值；同步列（sync_version/last_modified_by/sync_tombstones）。

**迁移策略**：`schema_migrations(version, description, applied_at)`；升级 = 幂等 `ALTER TABLE ... ADD COLUMN`（承 ReadAny migrations.ts 模式）。

## 6. 关键技术决策与风险

| # | 决策/风险 | 结论 / 缓解 |
|---|---|---|
| K1 | foliate-js patch layer 范围 | v1 仅 patch `transformTarget`（AI 注入）+ CFI + textWalker；`autoTransform/transformSource`（foliate fork 定制）v1 **不搬**，按需 v2+ |
| K2 | Skill script runtime | v1 用 **Node**（`new Function`/vm，简单）；QuickJS 隔离列 v2+（借 ReadAny 开放问题）。v1 script skill 仅跑受信内置脚本 |
| K3 | Hybrid 检索向量模型 | v1：本地 embedding（sqlite-vec + 小模型，如 bge-small/多语言）；维度/provenance 记录于 `vector_index_provenance` |
| K4 | SM-2 参数默认值 | EF 初始 2.5；评分 0-5（0=忘记→重学）；间隔按 SM-2 公式（实施期定精确系数） |
| K5 | TTS 本地引擎 | v1 默认 eSpeakNG（零依赖、离线）；cloud.ts 留接口、v1 可不实现 |
| R1（风险） | foliate-js v1.0.x 成熟度 | Phase1 GO/NO-GO gate：先抽 3 个真实 EPUB（含复杂 CSS）验证渲染，通过才全面替换（承 ReadAny EPUB_CONVERSION_PLAN 决策） |
| R2（风险） | SM-2 复习体验粗糙 | v1 接受「够用」；FSRS 升级列 v2+（已在需求 §8） |
| R3（风险） | 大 EPUB 移动端性能 | v1 仅桌面（Tauri），移动端 v2+；先保证桌面流畅 |

## 7. 测试策略（Testing）

- **单测**：每 repository / provider / retriever / skill-runtime 配 vitest 单测（含边界：空书、无 anchor CFI、冲突）。
- **集成**：引擎↔数据层（loadBook→annotate→persist）；AI 全链路（retrieval→chat→write artifact）。
- **e2e**：Phase6 用 Playwright/webapp-testing 跑「导入→RIA→复习」全闭环（对真实 EPUB 语料）。
- **TDD**：v1 功能（RIA/SuperMemo）严格 TDD——先写失败测试再实现。
- **语料**：建 3-5 本真实 EPUB（含复杂 CSS/大文件）作回归基准。
