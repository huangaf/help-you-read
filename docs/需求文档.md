## 1. 产品定位（What）

**help-you-read = local-first、AI 全流程介入的「AI 辅助电子书阅读器」。**

- **核心主张**（用户原话）：*把 9 种读书方法固化为软件功能，AI 在「读前 / 读中 / 读后 / 复习」全流程自动介入。*
- **与市面 AI 阅读器的差异**（研究结论）：
  - 市面 AI 阅读器普遍「重入库分析、轻复习巩固」——**help-you-read 补齐「复习」空白**（#6 SuperMemo 间隔重复），让阅读从「一次性消费」变成「持续内化」。[已确认差异化]
  - **跨书知识沉淀**（#8 芒格多元思维 / #9 共振阅读）作为 v2 旗舰差异化——把散落各书的碎片，沉淀成可查询、可推理的「知识网络」。[已确认排期 v2+]
- **非目标（Non-goals，v1 明确不做）**：多用户/账号体系、云端 SaaS 部署、社交分享市场、PDF/MOBI/DOCX（v1 仅 EPUB）、插件市场。[YAGNI]

## 2. 核心设计原则（Design Principles）

| # | 原则 | 含义 |
|---|---|---|
| P1 | **local-first** [已确认 D3/①] | 本地为真源；离线全功能可用（含 AI，可走本地 LLM）；跨设备同步是**可选开关** |
| P2 | **AI 全流程介入** [已确认] | AI 不是「附加问答按钮」，而是贯穿读前/读中/读后/复习四阶段的**协作者** |
| P3 | **技能系统（Skill）** [已确认 D5] | 9 种读书方法 → 9 个**预置 Skill** + 用户可对话创建自定义 Skill；access 分级（none/read/write/full）= AI 介入边界 |
| P4 | **YAGNI** [已确认 v1 scope] | v1 只做最小闭环（#1 RIA + #6 SuperMemo），跑通「读中→复习」再迭代 |
| P5 | **引擎解耦** [已确认 D1] | 渲染引擎（foliate-js）与 AI/数据层解耦；引擎可替换，上层功能不感知 |

## 3. 已确认设计决策（Locked Decisions）

| 决策项 | 结论 | 来源/理由 |
|---|---|---|
| **D1 EPUB 引擎** [已确认] | foliate-js，`vendor-from-main + own patch layer`（非 npm@1.0.1） | npm 版过老(2023-04)；main 有 165 commits of fixes；ReadAny 已验证 transformTarget 可行 |
| **D2 AI 架构** [已确认] | provider 抽象（本地 LLM / 外部 API）+ **Hybrid 检索：FTS5 + 向量，RRF 融合** | #9/#8 需强语义召回，FTS5 兜底精确关键词；向量用本地 sqlite-vec（无云依赖），兼顾 local-first |
| **D3 数据模型** [已确认] | **local-first SQLite；多态单表 `method_artifact`（8 法）+ 独立表 `review_items`（SuperMemo）** | 借 Omnigram AiResult 多态范式；8 法共享生命周期（生成→缓存/幂等→审阅→反馈）收敛进单表，SuperMemo 因时间/调度形态不同独立建表 |
| **D4 同步** [建议→默认采纳] | WebDAV，**双库物理隔离**（可同步轻数据 vs 本地专用向量）+ 墓碑 + 单调版本号；跨设备为**可选开关** | 借 ReadAny 同步引擎；向量/模型产物永不跨设备（换模型即作废） |
| **D5 技能系统** [已确认] | Skill（kind=prompt/agent/script）+ Capability Catalog + AI 对话创建 + access 分级 | 借 ReadAny skills-design.md；「9 方法→功能」的落地范式 |
| **TTS 引擎** [已确认] | **可插拔：本地默认（eSpeakNG/Mei）+ 云可选（OpenAI/ElevenLabs）** | local-first：离线可用为默认；云端作高质量可选项（读中·听书） |
| **#6 算法** [已确认] | **SM-2**（v1）；FSRS 列为 v2+ 可选升级 | SM-2 实现简单、参数少（EF/interval），v1 够用；FSRS 更准但 ~20 参数、复杂 |
| **#8 模型策展** [已确认] | v1/v2 starter 集：**逆向思维 / 概率与期望值 / 心理学认知偏差 / 经济学原理 / 系统论（反馈回路/涌现）** | 跨学科 starter，可后续增删 |
| **v1 范围** [已确认] | **最小闭环：#1 RIA + #6 SuperMemo**（读中→复习） | 最高频、最能体现「AI 辅助阅读」价值；先跑通全流程验证架构 |
| **跨书知识图谱** [已确认] | **v2+**（#8 芒格 / #9 共振 的知识图谱 + 跨书边注） | 最大差异化但实现最复杂（概念抽取/关联推理/跨设备同步），v1 先做扎实单书闭环 |

## 4. 9 种读书方法 × 4 阶段 功能矩阵

> `期` = v1（MVP）/ v2+。「AI 介入点」= 该功能里 AI 自动做什么。

| # | 方法 | 阶段 | v1/v2+ | 功能形态（Skill kind） | AI 介入点 |
|---|---|---|---|---|---|
| 1 | **RIA 便签**（R-重读 / I-述评 / A-应用） | 读中+读后 | **v1** | agent：选中→R/I/A 三栏便签，A2「贴墙」 | AI 辅助生成 I（复述）、A（应用）；R 存原文+CFI+前后文 |
| 2 | **四层次阅读**（Adler：字词/观点/评论） | 读前+读中 | v2+ | agent：定义问题→快速定位→主动阅读 4 问 | AI 生成「快速定位报告」+「4 问」 |
| 3 | **三遍阅读**（Paul Graham：速览/细读/内化） | 读前/中/后 | v2+ | agent：三遍递进（每遍不同深度） | AI 生成每遍摘要/批判 |
| 4 | **宝塔式**（邹韬奋：由广入深分层） | 读前+读中 | v2+ | agent：选书→金字塔分层（塔尖/塔身/塔基） | AI 推荐书单 + 生成层级摘要树 |
| 5 | **麦肯锡高效**（赤羽雄二：15min判断→集中3-7天） | 读前+读中+复习 | v2+ | agent：值不值得读→集中阅读→数据库输出 | AI 生成「值得读判定」+ 讨论问题 + 结构化入库 |
| 6 | **SuperMemo 间隔重复**（SM-2） | **复习** | **v1** | script（调度）+ agent（卡片生成） | AI 从划线/笔记/A2 生成卡片；SM-2 调度到期复习 |
| 7 | **名人读书法**（毛泽东批注/朱熹三到/爱因斯坦总-析） | 读前+读中 | v2+ | prompt/agent：按名人风格批注/视角化阅读 | AI 按 persona 生成风格化批注 |
| 8 | **芒格多元思维**（跨学科模型） | 读后+复习 | v2+ | agent：逆向拆解 + 跨学科模型映射 | AI 生成「逆向视角」+ 多元模型应用（#8 五 starter 模型） |
| 9 | **共振阅读**（渡边康弘：多书同主题互证） | 读前+读中 | v2+ | agent：斜读/跳读→找有用内容 + 跨书互证 | AI 生成「共振点」（与既有知识/其它书连接） |

> **v1 = #1 + #6**（读中→复习最小闭环）；其余 7 法进 v2+ 路线图（§8）。

## 5. v1 MVP 需求（详细）

### 5.1 #1 RIA 便签（读中 + 读后）

**目标**：用户选中/划线一段文本，一键生成 R/I/A 三栏便签；AI 辅助 I（复述）与 A（应用）；A2「贴墙」沉淀为长期卡片。

**功能需求（FR）**：
- FR1.1 选中文本触发：阅读器内选中/划线 → 「生成 RIA 便签」入口（工具条 + 快捷键）。
- FR1.2 **R（Recording）**：持久化原文 + CFI 定位 + `context_before`/`context_after`（前后文，离线可依据）。[已确认 D3③：上下文为一等需求]
- FR1.3 **I（Interaction/述评）**：AI 辅助生成「述评」——读者视角的复述与点评（可手动编辑覆盖）。
- FR1.4 **A（Application）**：AI 生成「如何在生活/工作中应用」建议；A2「贴墙」（标记为长期卡片，进复习池）。
- FR1.5 便签管理：列表、编辑、删除、按书/标签筛选。

**AI 介入点**：生成 I（复述）、A（应用）；输入 = R 原文 + 前后文 + 全书上下文（Hybrid 检索）。
**数据**：`method_artifact(method='ria_note')`，content = {R, I, A} 结构化 JSON + context。[已确认 D3]
**Skill kind / access**：`agent`（prompt + tools: `reader.getSelection`, `retrieval.search`, `notes.create`）/ access=`write`。
**验收（v1）**：对 3 本真实 EPUB，选中任意段落生成 RIA，R 含正确 CFI+前后文；I/A 可编辑；A2 贴墙后出现在复习池。

### 5.2 #6 SuperMemo 间隔重复（复习）

**目标**：从划线/笔记/A2「贴墙」卡片生成间隔重复卡；SM-2 调度到期复习；用户评分驱动 EF/interval 更新。

**功能需求（FR）**：
- FR6.1 卡片生成：从 #1 A2「贴墙」项 / 划线 / 笔记 → AI 生成 Q/A 卡片（question/answer + context）。
- FR6.2 **SM-2 调度** [已确认]：每卡维护 `ease_factor`(EF, 初始 2.5)、`interval_days`、`due_date`、`lapses`、`retrieval_count`；复习时用户评分 0-5 → 按 SM-2 更新 EF/interval。
- FR6.3 复习会话：每日「待复习」队列（按 due_date）；批量复习模式。
- FR6.4 卡片管理：编辑、删除、重学（lapse 重置）、按书/来源筛选。
- FR6.5 统计：本册/全局复习量、保持率（retention）、EF 分布。

**AI 介入点**：从划线/笔记/A2 生成卡片（question/answer）；输入 = 原文 + 前后文 + 全书上下文。
**数据**：**独立表 `review_items`**（非 method_artifact）：card_id, book_id, source_artifact_id, question, answer, context, due_date, interval_days, ease_factor, lapses, retrieval_count, last_reviewed_at。[已确认 D3：SuperMemo 独立建表]
**Skill kind / access**：`script`（SM-2 调度，确定性）+ `agent`（卡片生成）/ access=`write`。
**验收（v1）**：从 10 张 RIA-A2 卡生成复习卡；SM-2 评分后 EF/interval/due_date 正确更新；到期卡片出现在当日复习队列。

### 5.3 支撑功能（v1 必需）
- **书库**：EPUB 导入、元数据、书架管理、阅读进度（CFI）。
- **AI 对话（伴读）**：基于当前书/选中段 + Hybrid 检索的问答。
- **TTS 听书** [已确认]：可插拔引擎（本地默认 eSpeakNG + 云可选），流式合成、音色选择。
- **技能管理（Skills）**：预置 skill 启用/禁用；v1 含 `ria_note`、`supermemo_card_gen`。

## 6. 数据模型（schema overview；详细 DDL 见 P6 技术方案）

> local-first SQLite。v1 需建表：`books`, `annotations`(含 context), `notes`, `threads`, `messages`, `skills`, `reading_sessions`, **`method_artifact`(多态)**, **`review_items`(独立)**。

| 表 | 职责 | v1/v2+ | 关键字段（概要） |
|---|---|---|---|
| `books` | 书 + 元数据 + 进度 | v1 | id, file_path, format(=epub), title/author, progress, current_cfi, tags |
| `annotations` | 划线/批注（**含 context_before/after + CFI**）[已确认③] | v1 | id, book_id, cfi, text, context_before/after, color/style/type |
| `notes` | 自由笔记（可挂 highlight） | v1 | id, book_id, highlight_id(可空), cfi, title, content |
| `threads` / `messages` | AI 对话（规范化，非 JSON-blob）[借 ReadAny] | v1 | thread: book_id, memory_summary；message: role/content/citations/tool_calls/reasoning |
| `skills` | 预置 + 自定义 Skill（manifest）[借 ReadAny] | v1 | id, name, kind(prompt/agent/script), access, tools[], prompt, built_in |
| `reading_sessions` | 阅读会话时间序列（复习/习惯分析基础）[借⑤] | v1 | id, book_id, started_at/ended_at, total_active_time, pages_read |
| **`method_artifact`** | 多态单表：8 法 AI 产物 [已确认 D3②] | v1(ria_note) / v2+(其余7法) | id, book_id, **method**(判别列), content(JSON 方法特定结构), idempotency_key, helpful/dismissed |
| **`review_items`** | SuperMemo 间隔重复卡（独立表）[已确认 D3] | v1 | card_id, book_id, source_artifact_id, question/answer, context, due_date, interval_days, ease_factor, lapses |
| `concept_tags` / `concept_edges` | 跨书知识图谱（节点/边）[借④] | **v2+** | node: book_id, name, source, note_id；edge: source_id/target_id/weight/reason |
| `margin_notes` | 跨书「边注」（共振）[借④] | **v2+** | book_id, related_book_id, content, confidence, dismissed/helpful |

> **v1 数据模型 = 8 张表**（books/annotations/notes/threads/messages/skills/reading_sessions/method_artifact/review_items）。v2+ 增 concept_tags/concept_edges/margin_notes + method_artifact 新增 7 个 method 值。
> **双库隔离** [已确认 D4]：`*_local.db` 存向量 chunks（embedding BLOB + provenance），**不参与同步**。

## 7. 非功能需求（NFR）

- **NF1 local-first** [已确认]：无网络时核心功能（阅读/批注/RIA/复习/TTS本地）全可用；AI 可切本地 LLM。
- **NF2 同步** [已确认 D4]：WebDAV，双库隔离（向量不跨设备）+ 墓碑 + 单调版本号；**可选开关**，默认关。
- **NF3 权限** [已确认 D5]：access 分级（none/read/write/full）= AI 介入边界；full 才允许原始 DB 查询/脚本。
- **NF4 性能**：EPUB（≤2000 页）首屏 < 2s；AI 响应流式；复习队列加载 < 500ms。[建议，待 P6 定阈值]
- **NF5 隐私**：所有数据本地；云端（TTS云/外部API）仅用户显式开启且只传必要字段。
- **NF6 可观测**：AI 调用日志（prompt/token/耗时）；skill 运行日志。

## 8. v2+ 路线图（out of scope for v1）

- **方法层**：#2 四层次 / #3 三遍 / #4 宝塔 / #5 麦肯锡 / #7 名人（均落 `method_artifact` 新 method 值）。
- **知识图谱** [已确认 v2+]：#8 芒格（concept_tags/edges，逆向+跨学科）+ #9 共振（margin_notes 跨书边注）——**旗舰差异化**。
- **同步增强**：向量时钟/per-row Lamport counter（解决「相同 updatedAt 冲突需 manual」硬弱点）。
- **FSRS**：#6 调度算法从 SM-2 升级 FSRS（可选）。
- **格式扩展**：PDF / MOBI。
- **TTS 增强**：更多云端音色、跟读模式。

## 9. 未决 / 待细化（open items → P6 技术方案）

- RIA：I/A 生成的 **prompt 模板**（含 few-shot）；A2「贴墙」交互细节。
- SM-2：具体参数默认值、评分 UI（0-5 语义）、lapse 重置策略。
- `method_artifact.content` 各 method 的 **JSON schema**（v2+ 逐个定）。
- Skill script runtime：**QuickJS 隔离 vs Node eval**（借 ReadAny 开放问题）。
- Hybrid 检索：向量模型选型（本地 embedding 维度/端点）、RRF k 参数。
- TTS：本地引擎具体选型（eSpeakNG vs Mei）、云端 API 抽象。
- foliate-js patch layer 范围：transformTarget + CFI + textWalker 够不够？
