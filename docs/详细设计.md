## 1. 功能规格

### 1.1 书库管理（书架）

- 导入书籍：EPUB（主）/ PDF / TXT（渐进）
- 书籍元数据：标题、作者、封面、格式、导入时间、阅读状态（未读/在读/读完/归档）
- 书架视图：卡片列表，搜索（书名/作者），按状态/标签筛选

### 1.2 阅读器（三栏布局）

```
┌──────────┬────────────────────────┬──────────────────┐
│ 左栏      │ 中央阅读区              │ 右栏              │
│ 目录/标注  │ foliate-js 渲染        │ AI 对话/便签/档案 │
│ 分级标记   │ 高亮/批注交互           │ 上下文感知        │
└──────────┴────────────────────────┴──────────────────┘
```

- **中央**：EPUB 渲染（foliate-js），滚动/分页模式，字体/字号/主题设置
- **选中文本操作**：高亮（五色）/ 批注 / 生成 RIA 便签 / 选词即释 / 跳读标记
- **左栏**：章节目录、标注列表（按章节聚合）、分级重读标记
- **右栏**：AI 对话（感知当前位置+选中文本）、便签面板、读书档案面板

### 1.3 AI 方法引擎（9 种方法）

#### 1.3.1 四层次阅读
- **检视阅读报告（读前）**：输入全书文本 → 输出结构图（章节树+核心论点）、值不值得读评估、建议阅读方式
- **分析阅读问答（读中）**：RAG 检索 + 追问，答案带原文引用（章节/段落定位）
- **主题阅读（读后）**：跨书检索，同一主题聚合多书观点

#### 1.3.2 三遍阅读模式
- 模式一纵览：AI 生成全书梗概（对应三遍法第一遍）
- 模式二细节：AI 提供段落实时解释、批判性问题
- 模式三笔记：AI 基于高亮/便签整理成结构化笔记（对应三遍法第三遍）

#### 1.3.3 RIA 便签法
- 选中段落 → AI 生成三类便签：
  - **I**：用自己的话重述知识（1 张便签量级）
  - **A1**：关联自身相关经验（触发用户回忆，AI 给提示不给编造）
  - **A2**：具体行动计划（可执行、有时限）
- 便签可编辑、可归档
- **行动看板**：A2 便签聚合展示（贴墙），标注状态（待办/进行中/完成）

#### 1.3.4 宝塔式分级重读
- 书籍/章节分级：浏览（1 级）/ 精读（2 级）/ 最爱（3 级）
- 重读清单：按分级展示重读列表，记录重读次数与间隔

#### 1.3.5 麦肯锡读书档案
- 档案字段：读书目的（读前填写）、核心收获、行动计划、输出记录（读书笔记/书评/实践）
- 档案生成：AI 基于全书高亮+便签自动起草，用户可编辑
- 导出：Markdown / Obsidian

#### 1.3.6 SuperMemo 间隔重复
- **闪卡生成**：高亮/便签 → AI 生成 Q&A 闪卡（可编辑）
- **复习调度**：FSRS 算法（内置），每日复习队列
- **复习界面**：卡片翻转、自评（忘记/模糊/记得）、调度更新
- **导出**：Anki APKG 格式（渐进）

#### 1.3.7 名人读书法
- 不动笔墨：五色高亮 + 批注 + 圈点符号
- 跳读模式（鲁迅）：自动跳过已标记章节，聚焦整体理解
- 由薄到厚（华罗庚）：选中概念 → AI 展开概念图谱、关联定义与推理链

#### 1.3.8 芒格多元思维
- 跨书概念聚合：相同/相似概念跨书汇总
- 思维模型标签：为高亮/便签打思维模型标签（如复利、护城河、逆向思维）
- 知识网络图：概念-书籍-便签关系可视化（渐进）

#### 1.3.9 共振阅读
- 关键词定位：输入目标 → 语义检索定位相关内容段落
- 目标提问式阅读：以问题驱动阅读（AI 引导提问清单）
- 跟随高亮：阅读进度跟随高亮标记

### 1.4 阅读统计

- 阅读时长：每日/每周/每月趋势
- 热力图：GitHub 风格贡献图
- 书籍维度：每本阅读时长、完成度、连续天数

## 2. 数据模型（SQLite）

### 2.1 表结构

```sql
-- 书籍
CREATE TABLE books (
  id TEXT PRIMARY KEY,            -- uuid
  title TEXT NOT NULL,
  author TEXT,
  cover_path TEXT,
  format TEXT NOT NULL,           -- epub/pdf/txt
  file_path TEXT NOT NULL,
  file_hash TEXT UNIQUE,          -- 去重
  status TEXT DEFAULT 'unread',   -- unread/reading/finished/archived
  grade INTEGER DEFAULT 1,        -- 宝塔式分级 1浏览/2精读/3最爱
  total_chapters INTEGER,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- 章节
CREATE TABLE chapters (
  id TEXT PRIMARY KEY,
  book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  index INTEGER NOT NULL,
  title TEXT NOT NULL,
  content TEXT NOT NULL,          -- 章节全文
  char_count INTEGER,
  UNIQUE(book_id, index)
);

-- 高亮
CREATE TABLE highlights (
  id TEXT PRIMARY KEY,
  book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  chapter_id TEXT REFERENCES chapters(id) ON DELETE CASCADE,
  color TEXT DEFAULT 'yellow',    -- yellow/green/blue/pink/purple
  quote TEXT NOT NULL,            -- 原文摘录
  note TEXT,                      -- 批注
  cfi TEXT,                       -- EPUB 定位（epubcfi）
  page_ref TEXT,                  -- 页码/段落引用
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- RIA 便签
CREATE TABLE notes (
  id TEXT PRIMARY KEY,
  book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  highlight_id TEXT REFERENCES highlights(id) ON DELETE SET NULL,
  chapter_id TEXT REFERENCES chapters(id) ON DELETE CASCADE,
  type TEXT NOT NULL,             -- I / A1 / A2
  content TEXT NOT NULL,
  source_quote TEXT,              -- 关联原文
  status TEXT DEFAULT 'active',   -- active/done/archived（A2 行动状态）
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- 读书档案（麦肯锡）
CREATE TABLE reading_archives (
  id TEXT PRIMARY KEY,
  book_id TEXT NOT NULL UNIQUE REFERENCES books(id) ON DELETE CASCADE,
  purpose TEXT,                   -- 读书目的（读前）
  key_takeaways TEXT,             -- 核心收获
  action_plan TEXT,               -- 行动计划
  output TEXT,                    -- 输出记录
  ai_draft TEXT,                  -- AI 起草内容（可编辑）
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- 闪卡（间隔重复）
CREATE TABLE cards (
  id TEXT PRIMARY KEY,
  book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  source_highlight_id TEXT REFERENCES highlights(id) ON DELETE SET NULL,
  source_note_id TEXT REFERENCES notes(id) ON DELETE SET NULL,
  question TEXT NOT NULL,
  answer TEXT NOT NULL,
  due_at TEXT NOT NULL,           -- 下次到期时间
  interval_days REAL DEFAULT 0,   -- 当前间隔
  stability REAL DEFAULT 0,       -- FSRS stability
  difficulty REAL DEFAULT 5,      -- FSRS difficulty
  state INTEGER DEFAULT 0,        -- FSRS state (0=new,1=learning,2=review,3=relearning)
  reps INTEGER DEFAULT 0,
  lapses INTEGER DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- 阅读会话统计
CREATE TABLE reading_sessions (
  id TEXT PRIMARY KEY,
  book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  started_at TEXT NOT NULL,
  ended_at TEXT,
  duration_seconds INTEGER,
  chapter_id TEXT
);

-- 思维模型标签（芒格）
CREATE TABLE mental_models (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,      -- 如：复利、护城河、逆向思维
  description TEXT
);

CREATE TABLE highlight_mental_models (
  highlight_id TEXT NOT NULL REFERENCES highlights(id) ON DELETE CASCADE,
  model_id TEXT NOT NULL REFERENCES mental_models(id) ON DELETE CASCADE,
  PRIMARY KEY (highlight_id, model_id)
);

-- AI 配置
CREATE TABLE ai_config (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

### 2.2 关键索引

```sql
CREATE INDEX idx_chapters_book ON chapters(book_id);
CREATE INDEX idx_highlights_book ON highlights(book_id);
CREATE INDEX idx_notes_book_type ON notes(book_id, type);
CREATE INDEX idx_cards_due ON cards(due_at);
CREATE INDEX idx_sessions_book_time ON reading_sessions(book_id, started_at);
```

## 4. API 设计（Next.js Route Handlers）

### 4.1 书库

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/books` | 书库列表（含筛选/搜索） |
| POST | `/api/books` | 导入书籍（multipart 上传） |
| GET | `/api/books/[id]` | 书籍详情 + 章节列表 |

## 5. AI 方法引擎 Prompt 设计要点

### 5.1 通用约定

- 所有 Prompt 使用简体中文输出
- 结构化输出优先使用 JSON（`structuredOutput` 或 XML 包裹后解析）
- AI 生成内容均可被用户编辑，Prompt 末尾提示"如内容不符合你的理解，请直接编辑修正"

### 5.2 RIA 便签 Prompt 骨架

```
你是拆书家，帮助用户把书籍片段拆为己用。

原文片段：
<quote>{quote}</quote>

请生成三张便签：
1. I 便签：用自己的话重述这个知识点的核心（80-150字）
2. A1 便签：给出一个引导问题，帮用户回忆自己的相关经验（不要编造用户经历）
3. A2 便签：提出一个具体的行动计划（可执行、有明确对象和场景，30-80字）

输出 JSON：
{"I": "...", "A1_question": "...", "A2": "..."}
```

### 5.3 检视阅读报告 Prompt 骨架

```
对以下书籍做检视阅读分析：
书名：{title} 作者：{author}

分析维度：
1. 全书结构：章节树 + 每章核心论点（3-5 条）
2. 全书主题与主线论点
3. 核心论据类型（数据/案例/逻辑）
4. 值不值得读：目标读者、前置知识、阅读建议（精读/选读/略读）
5. 预计阅读方式：结合本书类型给出推荐阅读方法（对应方法库）
```

### 5.4 RAG 问答 Prompt 骨架

```
你是一个基于用户书库的阅读助手。严格基于检索到的原文回答，不得编造。
若检索内容不足以回答，明确说明"书中未找到相关内容"。

检索片段：
{context}

用户问题：{question}
阅读位置：{location}
选中文本：{selection}

回答要求：
1. 直接回答问题，引用片段时标注来源（章节+段落）
2. 如果问题涉及全书整体，说明可切换主题阅读模式
```

## 6. FSRS 间隔重复算法

采用 FSRS-4.5 标准实现（参考 `open-spaced-repetition/fsrs4js` 算法逻辑）：

- **参数**：stability、difficulty、due、state、reps、lapses
- **打分**：again(1) / hard(2) / good(3) / easy(4)
- **调度**：每次打分后更新 FSRS 参数并计算下一次 due
- **实现**：`lib/srs/fsrs.ts`，内置默认参数组（w），后续可基于用户复习历史优化
- **导出**：Anki APKG 导出渐进支持（M2 后置）
