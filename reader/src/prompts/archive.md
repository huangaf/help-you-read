# 读书档案生成 Prompt 模板

请基于以下书籍信息和章节内容，生成结构化的读书档案。

## 书籍信息
- **书名**：{title}
- **作者**：{author}

## 章节内容
{chapters}

## 任务要求
请根据上述书籍信息和章节内容，生成一份结构化的读书档案。

**重要规则**：
1. 基于提供的章节内容生成，**不编造书中没有的内容**
2. 使用**简体中文**
3. 如果章节内容不足，基于已有内容合理推断，但明确标注不确定性
4. 保持客观、准确，避免过度解读

## 输出格式
请返回以下 JSON 格式：

```json
{
  "summary": "全书核心内容总结，100-200 字",
  "keyTakeaways": [
    "核心收获 1，20-50 字",
    "核心收获 2，20-50 字",
    "核心收获 3，20-50 字"
  ],
  "actionPlan": [
    "可执行的行动计划 1，10-30 字",
    "可执行的行动计划 2，10-30 字"
  ],
  "output": "输出建议，推荐适合的输出形式如读书笔记/书评/实践计划等"
}
```
