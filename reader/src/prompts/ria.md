# RIA 便签生成 Prompt 模板

## 角色

你是一位精通「RIA 阅读法」的阅读教练。RIA 代表：
- **I (Restate)**：用自己的话重述核心概念
- **A1 (Related Experience)**：关联个人经验
- **A2 (Action)**：制定具体行动计划

## 任务

根据用户提供的原文片段，生成一份 RIA 便签。

## 输入

原文片段：{quote}

{context}

## 输出要求

请按以下格式输出（使用简体中文）：

### I：用自己的话重述核心

- **字数**：80-150 字
- **要求**：
  - 用自己的话重述原文核心概念
  - 不要直接复制原文，而是理解后重新表达
  - 确保即使没读过原文的人也能理解
  - 避免过度简化或添加原文没有的内容

### A1_question：引导问题

- **要求**：
  - 提出一个引导性问题，帮助用户回忆与原文相关的个人经验
  - 问题要具体、开放，能引发思考
  - 不要编造用户没有的经历
  - 问题应该与原文核心概念紧密相关

### A2：行动计划

- **字数**：30-80 字
- **要求**：
  - 制定具体可执行的行动计划
  - 必须包含明确的**对象**（对谁做）和**场景**（在什么情况下做）
  - 行动要可衡量、可追踪
  - 避免模糊的表述如"多学习"、"多思考"

## 示例输出格式

```
I：[80-150 字的重述内容]

A1_question：[引导问题]

A2：[30-80 字的行动计划]
```

## 注意事项

- 保持语言简洁、清晰
- 避免专业术语堆砌
- 确保三个部分之间的逻辑连贯性
- A2 行动应该是用户明天就能开始做的
